# 🌪️ Cleaning – 토네이도 모래 흩날리기

N×N 격자 가운데에서 시작한 토네이도가 **나선형으로 이동하며 모래를 정해진 비율로 흩뿌릴 때, 격자 밖으로 나간 모래의 양**을 구하는 시뮬레이션 문제 풀이입니다.
(백준 20057번 「마법사 상어와 토네이도」 유형)

## 모래가 퍼지는 비율

토네이도가 위로 이동할 때 기준:

```
          5%
    10%   α   10%
 2%  7%  [ ]   7%  2%
     1%   ●    1%
```

- 각 칸으로 비율만큼 모래가 이동하고, 남은 양(α)은 진행 방향 앞칸으로 이동합니다.
- 격자 밖으로 나간 모래는 따로 합산합니다.

## 파일 구조

| 파일 | 설명 |
| --- | --- |
| `Cleaning/Cleaning.java` | 상·하·좌·우 이동 시 모래 분배 구현 (범위 밖은 예외 처리로 합산) |
| `Cleaning/Cleaning2.java` | 가운데부터 나선형(1, 1, 2, 2, 3, 3 …)으로 이동하는 경로 구현 |

## 실행 방법

```bash
cd Cleaning
javac Cleaning.java
java Cleaning
```

`Java`

> 풀이 도중 저장한 코드라 두 파일이 아직 하나로 합쳐지지 않았고, 주석이 인코딩 문제로 깨져 있습니다.
